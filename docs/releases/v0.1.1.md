## 主な変更
- 話しながら文字が出るようにしました。話している途中の文字が、画面下の小さな表示に出ます（設定の「詳細設定」→「話しながら文字を出す」）。
- カーソルの前にある文を手がかりにするようにしました。すでに書いてある名前や用語と、表記がそろいやすくなります。パスワード欄は読みません。
- 話し終わったあとに、AI で言い間違いやいらない文を消せるようにしました（「10時、じゃなくて11時」→「11時」など）。設定の「AI で整える」で、端末の中で動く AI（Mac の Apple Intelligence、Ollama）とクラウドの AI（OpenAI、Anthropic など）から選べます。AI が元にない文を足した場合は、その結果を使わず、元の文字起こしをそのまま入れます。

## ダウンロード
- Windows：`Koeboard_0.1.1_x64-setup.exe`（ARM の PC は `arm64-setup.exe`）
- Mac：Apple シリコンは `aarch64.dmg`、Intel は `x64.dmg`
- Linux：`AppImage` / `deb` / `rpm`

## 初回起動時の注意
開発元の証明書による署名をまだしていないため、最初の起動で警告が出ます。
- Windows：「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」
- Mac：開けないと出たら、システム設定 →「プライバシーとセキュリティ」→「このまま開く」
